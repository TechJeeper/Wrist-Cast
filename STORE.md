## Description

Paste into each platform asset collection (max 1600 characters):

```
Wrist Cast is a micro-fishing simulator you can play by feel.

Flick your wrist to cast. Wait for a haptic bite. Press SELECT to hook, then rapidly alternate UP and DOWN to keep the tension meter in the green and reel the fish in.

Designed as an idle wrist game — look away and rely on vibration. SELECT also casts for emulator or accessibility.

• Accel cast with tunable sensitivity
• Bite waits: short, normal, or long
• Tension fight with Easy / Normal / Hard
• Common, rare, and legendary catches
• Persist catch count, streak, and best rarity
• Clay settings: vibe, quiet hours, wait, sensitivity, difficulty

Works on Pebble Time 2, Pebble Time, Pebble 2, and Pebble 2 Duo.
```

## Controls cheat sheet

| Input | Action |
| --- | --- |
| Wrist flick | Cast (when ready) |
| SELECT | Start / cast fallback / hook / dismiss result |
| UP / DOWN | Alternate to reel during fight |
| BACK | Leave fight/wait to ready; title exits |
